ProjectBridge

ProjectBridge is a Windows desktop application for selectively synchronizing project documents to the user's Google Drive.

Features

  • Manage multiple local projects.
  • Select specific directories for upload.
  • Preview changes before manual synchronization.
  • Update existing Google Drive files.
  • Configure an independent HTTP/SOCKS5 proxy.

ProjectBridge requests the Google Drive drive.file permission to manage files it creates or that the user explicitly authorizes.
