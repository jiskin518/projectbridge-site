ProjectBridge Privacy Policy

Last updated: November 12, 2026

Data Access

ProjectBridge accesses only local project files and directories selected by the user for synchronization.

Google Drive

ProjectBridge uses the Google Drive API with the drive.file permission to create and update files in the user's Google Drive.

Data Storage

Project settings and synchronization records are stored locally. OAuth tokens are stored using Windows Credential Manager.

Data Sharing

Selected files are transferred to the user's authorized Google Drive account. ProjectBridge does not operate an independent server for collecting project documents.

Data Deletion

Users can revoke ProjectBridge's Google account access through their Google Account settings and delete uploaded files from Drive.

Contact

For privacy inquiries, contact the developer using the support email shown on the Google OAuth consent screen.
